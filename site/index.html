Four tools · one C++ trading system

Tooling for the parts of C++ that nobody wants to do by hand.

Each of these came out of the same place: a repetitive, error-prone job in a real C++ codebase that was easier to automate than to keep doing carefully. Instrumenting function bodies, keeping a state machine and its code in step, chasing every override after an interface changes, and watching for the leaks that only show up hours in.

Instrumentation

Aspect Injector

Inserts — and cleanly strips — a ScopeTrace guard, a parameter check, or a try/catch into C++ function bodies. Function boundaries come from libclang's AST, not regex, so overloads and multi-line signatures survive. Every injected line carries a marker, so remove gives the file back byte for byte.

Python · libclang · JSON config · self-testing suite

Code generation

State Machine Toolkit

A Markdown table is the single source of truth. The toolchain validates the transition logic (dead states, orphans, conflicting rules), exports JSON, generates the full C++ state machine through Jinja2 templates, and renders an interactive Mermaid diagram of the same spec.

Refactoring

Interface Sync

Diffs an old interface against a new one, then walks every derived class header and updates it: obsolete override specifiers come off, new override stubs go on. It never deletes your declarations — the change is made visible, not decided for you.

Python · Clang AST · header-tree scan

Observability

Real-time Performance Monitor

Samples memory, thread count, handle count and context switches, then runs linear regression over the trend instead of comparing against a threshold. Wired into CI/CD, a statistically significant upward slope blocks the merge. Live dashboard, no setup.

So how do you actually use these tools?

By hand you have to prepare the inputs first: a Markdown transition table, an old header and a new one, a JSON rule file — then run the right script with the right paths. None of that is necessary any more. Describe the change in plain English and the AI writes those inputs and drives the tools for you. There is a live console on the page.
